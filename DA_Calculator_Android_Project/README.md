# D.A Arrears Calculator — Android App

This Android Studio project packages the calculator from the supplied ZIP as an installable Android app using a native Android WebView shell.

## Build an APK with GitHub Actions

1. Create a GitHub repository for this project.
2. Extract this ZIP and upload **all contents** to the repository root.
3. Commit the files to the `main` branch.
4. Open the **Actions** tab. The workflow **Build D.A Calculator APK** runs automatically after a push.
5. Open the completed run and download the `DA-Arrears-Calculator-APK` artifact.
6. Extract the downloaded artifact ZIP. It contains `app-debug.apk`.
7. Transfer `app-debug.apk` to your Android phone and install it. Allow installation from that source if Android asks.

You can also start a build manually from Actions → Build D.A Calculator APK → Run workflow.

## Firebase setup required

The calculator uses the Firebase Web SDK already configured in `app/src/main/assets/index.html`.

Because the Android WebView serves the bundled page from `https://appassets.androidplatform.net`, add this host to:

Firebase Console → Authentication → Settings → Authorized domains

Add:
`appassets.androidplatform.net`

Confirm Email/Password sign-in is enabled and both configured user accounts still have the expected UIDs. Publish the Firestore rules from the original package to the Firebase project if they are not already published.

The app needs an internet connection for Firebase sign-in, Firestore access, and Firebase password-reset email. Calculator inputs remain in WebView local storage on that device; they are not synced across devices.

## App features preserved

- Original D.A arrears calculator UI and calculations
- Firebase Admin/common-user sign-in
- Admin common-user access enable/disable
- Firebase password-reset email workflow
- Logout button
- Excel export, using Android's Save As picker

No logo image is included. App name: D.A Arrears Calculator.
